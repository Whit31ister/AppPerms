# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Contact the repository maintainer privately through the GitHub security contact for this project and include:

- A clear description of the issue
- Affected version or commit
- Reproduction steps or a proof of concept
- Potential impact

Please allow reasonable time for investigation and remediation before public disclosure.

## Scope

AppPerms is a local Android utility. Reports involving permission inventory disclosure, unsafe intent handling, dependency vulnerabilities, or accidental credential inclusion are especially useful.
